# The STER Farmhouse

> A quiet-luxury countryside holiday home nestled on a 1.5-acre tea farm in Tharaka Nithi County at the foot of Mount Kenya.

Built with clean HTML5, CSS3, and modern Vanilla JavaScript, mirroring the quiet-luxury editorial aesthetic of [Farmhouse Tigoni](https://farmhousetigoni.com/).

## Features
- **Editorial Quiet-Luxury Aesthetic**: Curated color palette (Highland Forest Green, Warm Linen Cream, and Muted Antique Gold) with Google Fonts typography (Spectral & IBM Plex Mono).
- **30 Authentic Visual Assets**: High-resolution property imagery alongside authentic excursion photography (Ngoko Waterfall, the 85m Mutunguruni Giant Tree, and Tharaka Nithi tea-picking hills).
- **Interactive Reservation Engine**: Real-time nights count, rate calculation, 50% deposit breakdown, and 1-click WhatsApp booking message generator.
- **Spaces & Amenities**: 3 private bedrooms (Master Suite, Twin Room, Tea View Room), Conclave banquet room, large viewing windows, chillout zone, and fully equipped kitchen.
- **Experiences & Excursions**: Detailed guide for Ngoko Waterfall, Mutunguruni Tree, Old Safari Rally walking/cycling trail, and Mt. Kenya Chogoria Gate.
- **Mobile-First UX**: Responsive layouts, touch-friendly mobile drawer menu, and floating reservation bar.
